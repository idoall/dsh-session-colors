<h3 id="cn-v0.1.13">中文</h3>

`0.1.13` 记录 DSH `0.2.1-rc.4` 兼容性，无需迁移。

支持最新 `0.2.1` 候选版本 `0.2.1-rc.4`（npm `next`），保留 `0.2.1-rc.3`、`0.2.1-rc.2`、`0.2.1-alpha.5`、`0.2.1-alpha.4`、`0.2.1-alpha.3`、`0.2.0-rc.2`、`0.2.0-rc.1`、`0.1.7-rc.2`、`0.1.7-rc.1` 和 `0.1.7-alpha.2` 的兼容声明。

### ⚠️ 调整

- **无需修改执行代码。** 本插件所消费的宿主接口与客户端槽位契约仍然兼容；现有加载范围（顶层 `engines.dsh`）已接纳 rc.4。
- **同步发布材料。** 中英文 README、CHANGELOG、版本声明与此 Release 统一为插件 `0.1.13`，发布后核对 npm 包内容。
- **验证边界明确。** 已完成逐包契约对比、门禁与单元测试检查；本次未重新完成浏览器视觉验证，既有 DOM 依赖限制不变。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@latest
```

重启 `dsh web` 后，浏览器端刷新页面即可；宿主半边只在启动时加载。

<h3 id="en-v0.1.13">English</h3>

`0.1.13` records DSH `0.2.1-rc.4` compatibility; no migration is needed.

Supports the latest `0.2.1` release candidate `0.2.1-rc.4` (npm `next`), retaining compatibility declarations for `0.2.1-rc.3`, `0.2.1-rc.2`, `0.2.1-alpha.5`, `0.2.1-alpha.4`, `0.2.1-alpha.3`, `0.2.0-rc.2`, `0.2.0-rc.1`, `0.1.7-rc.2`, `0.1.7-rc.1` and `0.1.7-alpha.2`.

### ⚠️ Changed

- **No executable-code change needed.** The consumed Host APIs and Client slot contracts remain compatible, and the existing load range (top-level `engines.dsh`) already admits rc.4.
- **Release materials aligned.** Both READMEs, CHANGELOG, manifest and this Release name plugin `0.1.13`; published npm contents are checked after release.
- **Verification limits stated.** Package-by-package contracts, the compatibility gate and unit tests were checked; browser visual verification was not repeated, and existing DOM-dependence limitations remain.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@latest
```

Restart `dsh web` and refresh the page: the Host half loads only at boot.
