DSH `0.2.1-alpha.5` 不需要任何改动——本插件消费的每个包都与 alpha.4 逐字节相同；本版只把它列为已验证兼容。

兼容最新 DSH `0.2.1-alpha.5`；已验证清单仍保留 `0.2.1-alpha.4`、`0.2.1-alpha.3`、`0.2.0-rc.2`、`0.2.0-rc.1`、`0.1.7-rc.2`、`0.1.7-rc.1` 与 `0.1.7-alpha.2`。`0.1.9` 及更早版本已发布，本版发布后 npm `latest` 指向 `0.1.10`。

<h3 id="cn-v0.1.10">⚠️ 调整</h3>

- **代码与声明范围都没变。** 加载范围本就接纳 `0.2.1-alpha.5`，声明位置也仍是 `0.1.9` 挪好的顶层 `engines.dsh`；本版只加了一条已验证版本记录。
- **alpha.4 → alpha.5 的差异实测为零。** 本插件用到的客户端产物（`ui-workspace`、`ui-conversation`、`ui-layout`、`client-modules`）、兼容性预检以及宿主侧 `host-webserver`、`client-connection` 全部逐字节相同。
- **升级后可见变化只有一处。** `0.2.1-alpha.5` 从此明确列为已验证兼容；色块、选择器与 marks 路由行为不变。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@latest
```

DSH `0.2.1-alpha.5` needs no change at all — every package this plugin consumes is byte-identical to alpha.4; this release only records it as verified.

Verified against the current DSH `0.2.1-alpha.5`; the list also keeps `0.2.1-alpha.4`, `0.2.1-alpha.3`, `0.2.0-rc.2`, `0.2.0-rc.1`, `0.1.7-rc.2`, `0.1.7-rc.1` and `0.1.7-alpha.2`. `0.1.9` and earlier are published; after this release npm `latest` points at `0.1.10`.
