### 修复与兼容性

- **修复原生抽屉色块跟随。** DSH `0.2.2-alpha.3` 保留抽屉内行 DOM，并通过框架的 `data-sidebar-collapsed`、`data-sidebar-drawer`、`data-sidebar-instant` 控制位置。关闭动画或即时收起时，旧监听可能漏掉变化。插件现在监听这些属性，及时重新测量色块，仍保留有界动画跟随与点击穿透；不修改会话、工作区或行顺序。
- **版本声明与文档同步。** 新增 alpha.3 兼容记录，保留此前 12 个已核查版本；中英文 README、CHANGELOG、Release 均同步到 `0.1.15`。现有 DSH engine 与两个 DSH peer 范围已经接纳 alpha.3，无需放宽；Host 代码、存储格式不变，从 `0.1.14` 升级无需迁移。
- **渠道不是验证清单。** 2026-11-03 核查 DSH npm：`alpha` → `0.2.2-alpha.3`，`latest` / `next` → `0.2.1-rc.5`。rc.5 不是本次安装运行时，未加入已验证清单。安装版 schemastery `3.18.6-alpha.2` API 可用，但不满足既有 `^3.18.2` 默认预发布 peer 规则；此声明限制未在本版调整。

### 验证与限制

- 官方 alpha.2 / alpha.3 产物对比、安装版 API 静态核查、Host 服务检查，以及 39 项单元测试通过；原生抽屉回归测试先失败、修复后通过。
- 自动化浏览器访问现有 GUI 返回 401，Client inspect 未提供可用槽位树；**不宣称真实 GUI、移动端或跨设备视觉验收完成**。没有启动临时服务、重启 DSH、修改其他插件或写入真实标记。
- 搜索结果行的 `result.id` 仍不被 fiber 回退识别，Host 写盘异常仍可能静默退化为内存；这些既有问题不在本次修复范围内。

### 升级


### Fix and compatibility

- **Track the native sidebar drawer.** DSH `0.2.2-alpha.3` retains drawer row DOM and moves it through the frame's `data-sidebar-collapsed`, `data-sidebar-drawer` and `data-sidebar-instant` attributes. The old observers could miss changes with reduced motion or instant close. The plugin now observes these attributes to remeasure chips promptly, retaining bounded animation tracking and click-through behaviour. It does not change Sessions, Workspaces or row order.
- **Synchronise versions and documentation.** Add alpha.3 compatibility while retaining the 12 previously assessed releases. Both READMEs, CHANGELOG and Release describe `0.1.15`. Existing DSH engine and both DSH peer ranges already admit alpha.3 and are unchanged. Host code and storage format are unchanged; no migration from `0.1.14` is needed.
- **Channels are not a verification list.** Registry check on 2026-11-03: DSH `alpha` → `0.2.2-alpha.3`, `latest` / `next` → `0.2.1-rc.5`. rc.5 is not the installed runtime assessed here and is not added to the verified list. The installed schemastery `3.18.6-alpha.2` API works but remains outside the default prerelease peer rule for `^3.18.2`; that declaration limitation is unchanged.

### Verification and limits

- Official alpha.2 / alpha.3 artifact comparison, installed API static review, Host service inspection and all 39 unit tests pass. The native-drawer regression test failed before the fix and passes afterwards.
- The automation browser received HTTP 401 from the existing GUI; Client inspection supplied no usable slot tree. **Real GUI, mobile and cross-device visual acceptance are not claimed.** No temporary server was started, DSH was not restarted, other plugins were not changed, and no real marks were written.
- Search-result `result.id` remains unrecognised by the fiber fallback; Host disk-write errors can still silently fall back to memory. These pre-existing issues are outside this patch.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@0.1.15
```

Restart `dsh web` yourself when convenient and refresh the page to load the installed package's new module generation. Publishing does not automatically update your profile. Colour data needs no migration.
