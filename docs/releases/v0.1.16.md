<h3 id="cn-v0.1.16">中文</h3>

| 插件版本 | 最新核查的 DSH | npm 渠道 |
| --- | --- | --- |
| `0.1.16`（本版） | `0.2.2-rc.1` | `latest`（发布后） |
| `0.1.15` | `0.2.2-alpha.3` | 已发布 |

### 兼容性与改动

- 新增 DSH `0.2.2-rc.1` 兼容记录，保留此前 13 个已核查版本；同步双语 README、CHANGELOG 与 Release 版本号。
- 无执行代码修改。保留 `0.1.15` 的原生抽屉属性跟随修复；Host、存储格式及 DSH engine / peer 范围不变，从 `0.1.15` 升级无需迁移。
- 2026-11-04 npm 渠道：DSH `next` → `0.2.2-rc.1`，`alpha` → `0.2.2-alpha.3`，`latest` → `0.2.1-rc.5`。rc.5 不在已验证清单内。
- 当前安装的 schemastery `3.19.0` 满足既有 `^3.18.2`；上一轮预发布 peer 不匹配问题不再适用于当前安装，无需调整依赖。

### 验证与限制

- 对比官方 alpha.3 / rc.1：相关 webServer、connection、locale、会话、布局、工作区、槽位渲染器、会话标准 props 及 primitives 的 `lib` 产物相同；client-modules 只更新构建提交号。可用安装产物与 registry 对应文件一致；primitives 在此安装中由外壳提供，而非独立 lib 文件。
- 39 项单元测试通过；使用安装的 schemastery 额外验证 Config、apply 和模拟内存 GET 路由。没有写入真实标记。
- Host inspect 确认路由与鉴权契约；Client inspect 确认 `shell.overlay` 的 `session-color-chips` 激活，但未返回可用的头部 utilities 树。**未完成真实 GUI、移动端或跨设备视觉验收**，不把注册成功当作视觉验收。
- 搜索结果身份回退、写盘失败静默退化等既有边界不在本次修改范围内。没有修改其他插件、部署 profile、启动临时服务或重启 DSH。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@0.1.16
```

发布不会自动更新用户 profile。安装后由用户在方便时重启 DSH 并刷新页面，颜色数据无需迁移。

| Plugin version | Newest assessed DSH | npm channel |
| --- | --- | --- |
| `0.1.16` (this release) | `0.2.2-rc.1` | `latest` (after publishing) |

### Compatibility and changes

- Add DSH `0.2.2-rc.1` compatibility, retaining the 13 previously assessed versions; synchronise both READMEs, CHANGELOG and Release versions.
- No executable-code changes. Retain `0.1.15` native-drawer attribute tracking; Host, storage format and DSH engine / peer ranges are unchanged. No migration from `0.1.15` is needed.
- Registry channels on 2026-11-04: DSH `next` → `0.2.2-rc.1`, `alpha` → `0.2.2-alpha.3`, `latest` → `0.2.1-rc.5`. rc.5 is not on the verified list.
- Installed schemastery `3.19.0` satisfies the existing `^3.18.2`; the previous prerelease peer mismatch no longer applies to this installation. No dependency adjustment is needed.

### Verification and limits

- Compare official alpha.3 / rc.1: relevant webServer, connection, locale, conversation, layout, workspace, slot renderer, standard Session props and primitives have identical `lib` artifacts; client-modules only changes its embedded build commit. Available installed artifacts match registry counterparts; primitives are supplied by the shell rather than standalone lib files here.
- All 39 unit tests pass; an extra check using installed schemastery exercises Config, apply and a mocked in-memory GET route. No real marks were written.
- Host inspection confirms route/authentication contracts; Client inspection confirms active `session-color-chips` in `shell.overlay`, but returns no available header-utilities tree. **Real GUI, mobile and cross-device visual acceptance remain unverified**; registration is not visual acceptance.
- Existing search-result identity fallback and silent disk-write fallback limits are outside this patch. No other plugin, profile deployment, temporary server or DSH restart was involved.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@0.1.16
```

Publishing does not automatically update your profile. After installation, restart DSH yourself when convenient and refresh the page. Colour data needs no migration.
