### ⚠️ 调整

- **无需修改执行代码。** 本插件消费的接口仍然存在且向后兼容：宿主 `webServer.register` 继续接受 `kind`/`path`/`handler` 处理器路由（新增的 Fetch 资源形式是可选的），`connection.requestRejection` 未变；浏览器 `__ModuleLoader__.load({ id, factory })` 格式、`react`/`react-dom` 内置模块、两个目标槽位（`conversation.session.header.utilities` 与 `shell.overlay`）及其 owner props 均未变。
- **加载范围新增一个分支。** 旧范围在 DSH 的 `includePrerelease` 预检下本来就能进 `0.2.2-alpha.2`，但按 node-semver 默认规则，预发布只能被写出同一 `major.minor.patch` 的比较符接纳。因此 `engines.dsh` 与两个 peer 范围都追加 `>=0.2.2-alpha.2 <0.3.0`，让声明与已验证版本一致。
- **侧栏行契约仍然成立。** 会话行仍带 `data-row-key="session:<id>"`、`role="treeitem"`、`aria-selected`，行高仍是 32px；行动画整体搬进了外壳内置的 `@deepseek-ai/dsh-client-ui-primitives` 静态模块（`rowKeys` 与 Web Animations 行为不变），退场克隆仍会去掉 `data-row-key`，不会给淡出副本多画色块。
- **验证边界明确。** 已完成逐包契约对比、一次性 profile 的启动与路由回读、以及 38 个单元测试；浏览器里的实际渲染本次没有复看，既有 DOM 依赖限制不变。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@latest
```

重启 `dsh web` 后，浏览器端刷新页面即可；宿主半边只在启动时加载。从 `0.1.13` 升级无需迁移。

### ⚠️ Changed

- **No executable-code change needed.** Every interface this plugin consumes still exists and stays backward compatible: the Host `webServer.register` still accepts `kind`/`path`/`handler` routes (the new Fetch-resource form is optional), `connection.requestRejection` is unchanged, and the browser `__ModuleLoader__.load({ id, factory })` format, the `react`/`react-dom` seeds, both target slots (`conversation.session.header.utilities` and `shell.overlay`) and their owner props are unchanged.
- **The load range gains one alternative.** DSH's `includePrerelease` precheck already admitted `0.2.2-alpha.2` under the old range, but node-semver's default rule only admits a prerelease through a comparator naming the same `major.minor.patch`. `engines.dsh` and both peer ranges therefore append `>=0.2.2-alpha.2 <0.3.0`, so the declaration matches the verified release.
- **The sidebar row contract still holds.** Session rows keep `data-row-key="session:<id>"`, `role="treeitem"`, `aria-selected` and the 32 px height; the row animation moved wholesale into the shell-seeded `@deepseek-ai/dsh-client-ui-primitives` static module (same `rowKeys` and Web-Animations behaviour), and exit clones still drop `data-row-key`, so no chip is painted for a fading copy.
- **Verification limits stated.** Package-by-package contracts were compared, a disposable profile booted the release and round-tripped its routes, and all 38 unit tests pass; the rendered appearance in a real browser was not re-inspected, and existing DOM-dependence limitations remain.

### Upgrade

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@latest
```

Restart `dsh web` and refresh the page: the Host half loads only at boot. Upgrading from `0.1.13` needs no migration.
