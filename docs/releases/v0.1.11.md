DSH `0.2.1-rc.2` 不需要任何改动——本插件消费的每个包都与 alpha.5 逐字节相同；本版把它列为已验证兼容。

兼容最新 DSH `0.2.1-rc.2`；已验证清单保留 `0.2.1-alpha.5`、`0.2.1-alpha.4`、`0.2.1-alpha.3`、`0.2.0-rc.2`、`0.2.0-rc.1`、`0.1.7-rc.2`、`0.1.7-rc.1` 与 `0.1.7-alpha.2`。`0.1.10` 及更早版本已发布，本版发布后 npm `latest` 指向 `0.1.11`。

<h3 id="cn-v0.1.11">⚠️ 调整</h3>

- **代码与加载范围都没变。** `0.2.1` 线本就接纳该元组的预发布版本，所以这个 RC（以及将来的 `0.2.1` 正式版）都不需要新的范围分支；声明位置仍是 `0.1.9` 挪好的顶层 `engines.dsh`。
- **alpha.5 → rc.2 的差异实测为零。** 本插件用到的客户端产物（`ui-workspace`、`ui-conversation`、`ui-layout`、`client-modules`）、兼容性预检以及宿主侧 `host-webserver`、`client-connection` 全部逐字节相同。
- **升级后可见变化只有一处。** `0.2.1-rc.2` 从此明确列为已验证兼容；色块、选择器与 marks 路由行为不变。

### 升级

```sh
dsh plugin --profile web add @idoall/dsh-session-colors@latest
```

DSH `0.2.1-rc.2` needs no change at all — every package this plugin consumes is byte-identical to alpha.5; this release records it as verified.

Verified against the current DSH `0.2.1-rc.2`; the list keeps `0.2.1-alpha.5`, `0.2.1-alpha.4`, `0.2.1-alpha.3`, `0.2.0-rc.2`, `0.2.0-rc.1`, `0.1.7-rc.2`, `0.1.7-rc.1` and `0.1.7-alpha.2`. `0.1.10` and earlier are published; after this release npm `latest` points at `0.1.11`.

<h3 id="en-v0.1.11">⚠️ Changed</h3>

- **Neither the code nor the load range moved.** The `0.2.1` line already admits prereleases of that tuple, so this RC — and the future `0.2.1` final release — need no new alternative; the declaration stays in the top-level `engines.dsh` that `0.1.9` moved it to.
- **The measured alpha.5 → rc.2 difference is zero.** The client bundles this plugin touches (`ui-workspace`, `ui-conversation`, `ui-layout`, `client-modules`), the compatibility precheck, and the Host-side `host-webserver` and `client-connection` are all byte-identical.
- **There is one visible upgrade effect.** `0.2.1-rc.2` is now explicitly listed as verified; chips, picker and the marks route behave exactly as before.
